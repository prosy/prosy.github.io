● EVALUATION · FRONTIER MODELS

I ran the test that killed my own thesis.

  • Drove Gemini and Perplexity through 30 owner's-manual questions across two manuals, twice each — 119 answers scored, every citation logged.
  • I went in believing the citation slot was empty. It is — but only on Gemini, which structurally won't show sources at all. Where the slot can actually be filled, Perplexity fills it 98% of the time, and incumbents already own it.
  • So the opening isn't open. I changed the plan, not the data.

● POINT OF VIEW · GREG PROSL

The bet, and what's next.

  • My bet: most agentic-commerce work builds the consumer agent and stops. The durable half is the protocol layer other companies' agents transact through — so I built both.
  • It works: a live MCP gateway in both directions, a public agent-to-agent surface where every skill is off until explicitly allowed, and 880+ Airlines, Hotels, Car rental and Travel Insurers in the marketplace as agents — two integrated end to end.
  • What I'd build next: the commercial layer on top — placement, take-rate, and the merchant terms that make a two-sided agent marketplace pay. The rails are built; terms are under negotiation now.
  • Why it maps to Agentic Commerce: different vertical, same problem — an agent is only as useful as the supply it can read, and the transaction has to be safe enough that a brand will allow it.
